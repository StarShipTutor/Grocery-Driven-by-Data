## Usage

When starting a new AI session, reference relevant directives to establish context.

## Directive Format

Each directive should include:
1. **Purpose** — What this directive helps accomplish
2. **Prerequisites** — What must be in place before following
3. **Steps** — Numbered, actionable instructions
4. **Verification** — How to confirm success
