## Session Handoff Template

When ending a session, create a `session_YYYYMMDD.md` file with:
1. **Completed** — Tasks finished this session
2. **In Progress** — Partially completed work
3. **Next Steps** — Recommended actions for next session
4. **Blockers** — Issues requiring resolution
5. **Notes** — Any relevant context
